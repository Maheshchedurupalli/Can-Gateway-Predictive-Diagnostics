# Firmware (STM32 + FreeRTOS)

Planned firmware for the CAN node.

## Planned modules
- CAN initialisation (500 kbps, CAN 2.0B)
- FreeRTOS TX task: periodic signal frames
- FreeRTOS RX task: receive and filter frames
- Error handling: bus-off recovery, error counters

## Status
Planning stage. Code will be added as each module is built and tested.
